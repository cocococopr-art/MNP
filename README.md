# MNPサイト アイコン実装セット

## GitHubに置くファイル
リポジトリの `index.html` と同じ階層へ、このフォルダ内のファイルをすべて置いてください。

## index.html
`<head>` 内へ `head-snippet.html` の内容を貼り付けます。

## iPhoneでアプリ化
Safariで公開サイトを開き、共有ボタン → ホーム画面に追加。

## Androidでアプリ化
Chromeで公開サイトを開き、メニュー → ホーム画面に追加／アプリをインストール。

## キャッシュ注意
アイコンを差し替えてもすぐ変わらない場合があります。
ファイル名を変更するか、ブラウザキャッシュを削除してください。
